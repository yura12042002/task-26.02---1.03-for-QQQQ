## Задача 5 — `groupBy(array, key)`

**Что сделать:** написать универсальную группировку — обобщение `groupByAge` из дня 1. Принимает массив объектов и имя ключа, возвращает объект, где ключ — значение поля, значение — массив элементов.

**Обязательный метод:** `reduce`

**Правила:**
- Порядок элементов внутри каждой группы = порядку во входном массиве
- Если у элемента нет ключа → группа `"unknown"`
- Не мутировать входные данные

**Критерии "готово":**
1. `groupBy(users, "role")` → `{ admin: [Alice, Charlie], user: [Bob, Eva], moderator: [David] }`
2. `groupBy(users, "city")` → `{ Moscow: [Alice, David, Eva], Perm: [Bob, Charlie] }`
3. `groupBy([], "role")` → `{}`
4. Элемент без ключа попадает в группу `"unknown"`
5. Порядок внутри групп сохранён
6. Входной массив не мутирован

**Крайние случаи:**
- `groupBy([], "x")` → `{}`
- `groupBy([{a:1}, {b:2}], "a")` → `{ "1": [{a:1}], unknown: [{b:2}] }`
- Все элементы с одинаковым значением ключа → один ключ, все в одном массиве

**Типовые ошибки:**
1. Копирует `groupByAge` и забывает заменить `age` на параметр `key`
2. `acc[value] = [item]` — перезаписывает группу вместо добавления
3. Не обрабатывает отсутствие ключа — получает группу `"undefined"` вместо `"unknown"`
4. Использует `item[key] || "unknown"` — ломается на falsy-значениях (0, "", false)

**Мини-проверка:**

```js
groupBy(users, "role");
// → {
//   admin:     [{ id: 1, name: "Alice", ... }, { id: 3, name: "Charlie", ... }],
//   user:      [{ id: 2, name: "Bob", ... }, { id: 5, name: "Eva", ... }],
//   moderator: [{ id: 4, name: "David", ... }]
// }

groupBy(users, "city");
// → {
//   Moscow: [Alice, David, Eva],
//   Perm:   [Bob, Charlie]
// }

groupBy([], "role");
// → {}

groupBy([{ x: 1 }, { y: 2 }], "x");
// → { "1": [{ x: 1 }], unknown: [{ y: 2 }] }
```

## Задача 6 — `indexBy(array, key)`

**Что сделать:** создать объект-индекс, где ключ — значение поля, а значение — сам элемент. Отношение «один к одному» (в отличие от groupBy).

**Обязательный метод:** `reduce`

**Правила:**
- Если несколько элементов с одинаковым значением ключа → **последний перетирает предыдущий**
- Не мутировать входные данные
- Пустой массив → `{}`

**Критерии "готово":**
1. `indexBy(users, "id")` → `{ "1": Alice, "2": Bob, "3": Charlie, "4": David, "5": Eva }`
2. При дубликатах: `indexBy([{id:1,v:"a"},{id:1,v:"b"}], "id")` → `{ "1": {id:1,v:"b"} }`
3. `indexBy([], "id")` → `{}`
4. Ключи объекта — строки (JS автоматически преобразует)
5. Один проход (reduce)

**Крайние случаи:**
- `indexBy([], "id")` → `{}`
- Дубликаты ключей: последний элемент побеждает
- `indexBy(users, "age")` → `{ "22": Eva, "30": Charlie, "35": David }` (Alice и Bob перезаписаны)

**Типовые ошибки:**
1. Путает `indexBy` и `groupBy` — возвращает массивы вместо одного элемента
2. Пытается проверять дубликаты и бросать ошибку (по условию — перезаписывать)
3. Забывает, что ключи объекта всегда строки — удивляется, что `result[1]` работает как `result["1"]`

**Мини-проверка:**

```js
const byId = indexBy(users, "id");
byId["1"];
// → { id: 1, name: "Alice", role: "admin", age: 30, city: "Moscow" }

byId["5"];
// → { id: 5, name: "Eva", role: "user", age: 22, city: "Moscow" }

Object.keys(byId).length;
// → 5

indexBy([], "id");
// → {}

// Дубликаты: последний побеждает
indexBy(users, "age");
// → { "22": { id: 5, name: "Eva", ... }, "30": { id: 3, name: "Charlie", ... }, "35": { id: 4, name: "David", ... } }
```

## Задача 7 — `pluck(array, key)`

**Что сделать:** извлечь массив значений по указанному ключу из массива объектов. Аналог "вытащить одну колонку из таблицы".

**Обязательный метод:** `map`

**Правила:**
- Если у элемента нет ключа → `undefined` в результирующем массиве (не пропускать, не фильтровать)
- Длина результата === длина входного массива
- Не мутировать входные данные

**Критерии "готово":**
1. `pluck(users, "name")` → `["Alice", "Bob", "Charlie", "David", "Eva"]`
2. `pluck(users, "age")` → `[30, 22, 30, 35, 22]`
3. `pluck([], "name")` → `[]`
4. `pluck(users, "nonExistent")` → `[undefined, undefined, undefined, undefined, undefined]`
5. Длина результата = длина входного массива
6. Используется `map`

**Крайние случаи:**
- `pluck([], "x")` → `[]`
- `pluck([{a:1}, {b:2}], "a")` → `[1, undefined]`
- `pluck(users, "id")` → `[1, 2, 3, 4, 5]`

**Типовые ошибки:**
1. Использует `filter` вместо `map` — теряет элементы без ключа, длина результата не совпадает
2. Проверяет `if (item[key])` и пропускает falsy-значения (0, "", false)
3. Путает `map` с `forEach` — `forEach` не возвращает массив

**Мини-проверка:**

```js
pluck(users, "name");
// → ["Alice", "Bob", "Charlie", "David", "Eva"]

pluck(users, "city");
// → ["Moscow", "Perm", "Perm", "Moscow", "Moscow"]

pluck([], "name");
// → []

pluck([{ a: 1 }, { b: 2 }, { a: 3 }], "a");
// → [1, undefined, 3]
```

## Задача 8 — `getAdults(users, minAge)`

**Что сделать:** вернуть новый массив пользователей, у которых `age >= minAge`.

**Обязательный метод:** `filter`

**Правила:**
- Не мутировать входной массив
- Пустой массив → `[]`
- Граничное значение (`age === minAge`) — включается в результат

**Критерии "готово":**
1. `getAdults(users, 30)` → массив из 3 объектов (Alice, Charlie, David)
2. `getAdults(users, 100)` → `[]`
3. `getAdults([], 18)` → `[]`
4. Входной `users` не изменён
5. Используется `filter`

**Крайние случаи:**
- `getAdults([], 18)` → `[]`
- `getAdults(users, 0)` → все 5 пользователей (все >= 0)
- `getAdults(users, 35)` → `[David]` (только один)
- `getAdults(users, 36)` → `[]`

**Типовые ошибки:**
1. Пишет `age > minAge` вместо `age >= minAge` — теряет граничный случай
2. Мутирует массив: `users.splice(...)` вместо `filter`
3. Возвращает имена/boolean вместо объектов (путает `filter` и `map`)

**Мини-проверка:**

```js
getAdults(users, 30);
// → [
//   { id: 1, name: "Alice", age: 30, ... },
//   { id: 3, name: "Charlie", age: 30, ... },
//   { id: 4, name: "David", age: 35, ... }
// ]

getAdults(users, 100);
// → []

getAdults([], 18);
// → []

getAdults(users, 22);
// → все 5 пользователей
```
