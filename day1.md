## Задача 1 — `sum(numbers)`

**Что сделать:** написать функцию, которая принимает массив чисел и возвращает их сумму.

**Обязательный метод:** `reduce`

**Правила:**
- Пустой массив → `0`
- Всегда передавай `initialValue: 0`

**Критерии "готово":**
1. `sum([1, 2, 3])` возвращает `6`
2. `sum([])` возвращает `0`
3. `sum([10])` возвращает `10`
4. Используется `reduce` с `initialValue`
5. Функция чистая — не мутирует входной массив

**Крайние случаи:**
- `sum([])` → `0` (без `initialValue` будет TypeError)
- `sum([-5, 5])` → `0`
- `sum([100])` → `100`

**Типовые ошибки:**
1. Забыл `initialValue` → на `[]` получаешь `TypeError`
2. Написал `reduce((a, b) => a += b)` — оператор `+=` лишний, достаточно `a + b`
3. Возвращает `NaN` если в массиве есть `undefined` — но по контракту входят только числа

**Мини-проверка:**

```js
sum([1, 2, 3]);        // → 6
sum([]);               // → 0
sum([10]);             // → 10
sum([-1, -2, -3]);     // → -6
```

## Задача 2 — `countByRole(users)` (два варианта)

**Что сделать:** написать функцию, которая возвращает объект `{ role: количество }`. Сделать **две реализации**: через `reduce` и через `for...of`.

**Обязательные методы:** `reduce` (вариант A) и `for...of` (вариант B)

**Правила:**
- Не мутировать входной массив и объекты внутри
- Пустой массив → `{}`

**Критерии "готово":**
1. Возвращает `{ admin: 2, user: 2, moderator: 1 }` для данных `users`
2. Оба варианта дают одинаковый результат
3. `countByRole([])` → `{}`
4. Входной массив `users` после вызова не изменён
5. Используются именно `reduce` / `for...of`

**Крайние случаи:**
- `countByRole([])` → `{}`
- Все с одной ролью: `countByRole([{role:"admin"},{role:"admin"}])` → `{admin: 2}`

**Типовые ошибки:**
1. Забыл `initialValue: {}` в reduce → первым аккумулятором станет объект пользователя
2. В `for...of` забыл инициализировать `result = {}` перед циклом
3. Пишет `acc[role] = acc[role] + 1` без проверки — на первом вхождении будет `NaN`
4. Мутирует входные объекты (добавляет поля)

**Мини-проверка:**

```js
countByRole(users);
// → { admin: 2, user: 2, moderator: 1 }

countByRole([]);
// → {}

countByRole([{ role: "guest" }, { role: "guest" }]);
// → { guest: 2 }
```

## Задача 3 — `countBy(array, key)`

**Что сделать:** написать универсальную функцию подсчёта по произвольному ключу. Это обобщение `countByRole`.

**Обязательный метод:** `reduce`

**Правила:**
- Если у элемента нет указанного ключа → считать его как `"unknown"`
- Пустой массив → `{}`
- Не мутировать входные данные

**Критерии "готово":**
1. `countBy(users, "city")` → `{ Moscow: 3, Perm: 2 }`
2. `countBy(users, "role")` → `{ admin: 2, user: 2, moderator: 1 }`
3. `countBy([], "role")` → `{}`
4. Элемент без ключа попадает в `"unknown"`
5. Функция чистая
6. Один проход (reduce)

**Крайние случаи:**
- `countBy([], "anything")` → `{}`
- `countBy([{a: 1}, {b: 2}], "a")` → `{ "1": 1, "unknown": 1 }` (у второго нет ключа `a`)
- `countBy(users, "nonExistentKey")` → `{ unknown: 5 }`

**Типовые ошибки:**
1. Не обрабатывает отсутствие ключа → получает `undefined` как ключ объекта (строка `"undefined"` вместо `"unknown"`)
2. Проверяет `if (!item[key])` вместо `if (!(key in item))` — ломается на falsy-значениях (0, "")
3. Копирует код из `countByRole` и забывает заменить `role` на параметр `key`

**Мини-проверка:**

```js
countBy(users, "city");
// → { Moscow: 3, Perm: 2 }

countBy(users, "role");
// → { admin: 2, user: 2, moderator: 1 }

countBy([{ a: 1 }, { b: 2 }, { a: 1 }], "a");
// → { "1": 2, unknown: 1 }

countBy([], "role");
// → {}
```

## Задача 4 — `groupByAge(users)`

**Что сделать:** сгруппировать пользователей по возрасту. Ключ — возраст (число/строка), значение — массив объектов пользователей.

**Обязательный метод:** `reduce`

**Правила:**
- Значения — полные объекты пользователей, **не** имена
- При одинаковом возрасте **добавлять** в массив, не перезаписывать
- Порядок внутри групп = порядок во входном массиве
- Не мутировать входные данные

**Критерии "готово":**
1. Результат содержит ключи `"22"`, `"30"`, `"35"`
2. `result["22"]` — массив из 2 объектов (Bob, Eva)
3. `result["30"]` — массив из 2 объектов (Alice, Charlie)
4. `result["35"]` — массив из 1 объекта (David)
5. `groupByAge([])` → `{}`
6. Входной `users` не изменён

**Крайние случаи:**
- `groupByAge([])` → `{}`
- Все пользователи одного возраста → один ключ, все в одном массиве
- Один пользователь → `{ "30": [{ ... }] }`

**Типовые ошибки:**
1. `acc[age] = [item]` вместо `push` / `concat` → перезаписывает при повторном возрасте
2. Забыл проверить существование ключа: `acc[age].push(item)` без `if` → TypeError
3. Возвращает имена вместо объектов
4. Пушит прямо во входные данные вместо создания нового массива в аккумуляторе

**Мини-проверка:**

```js
const result = groupByAge(users);

result["22"];
// → [{ id: 2, name: "Bob", ... }, { id: 5, name: "Eva", ... }]

result["30"];
// → [{ id: 1, name: "Alice", ... }, { id: 3, name: "Charlie", ... }]

Object.keys(result).length;
// → 3

groupByAge([]);
// → {}
```
